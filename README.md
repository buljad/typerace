    # ⌨️ Клавогонки IT // Speed Typing Arena

Соревновательный аттракцион проверки скорости печати для стендов ИТ-конференций.
Результаты заездов сохраняются в `leaderboard.json` с защитой персональных рекордов.

---

## 🚀 Быстрый запуск

### Вариант 1: Python

```bash
python3 server.py

Вариант 2: Node.js
Bash

node server.js

Открыть в браузере: http://localhost:3000
🔒 Механика защиты участников

    Telegram-хэндл (@handle): выступает уникальным идентификатором участника.

    4-значный PIN: задается участником при первом заезде. Предотвращает кражу ника и подделку результатов другими гостями.

    Personal Best: при повторных заездах сохраняется наивысший результат (CPM). Если участник набрал меньше своего рекорда, база данных оставляет прежний лучший показатель.

⚖️ Калибровка текстов

Все цитаты в пуле стандартизированы:

    Строгая длина: 114–119 символов.

    Сбалансированный микс: русский связный текст + общеупотребительные английские IT-термины (production, backend, deploy, pipeline, cluster).

    Равные условия сложности для всех участников стенда.
